# Ukraine_Alert_Spon

Асинхронний скрипт для моніторингу повітряних тривог в Україні та автоматичного керування системою оповіщення XC-9000.

## 🚀 Особливості

- ✅ **Асинхронний підхід** - ефективна робота з багатьма регіонами одночасно
- ✅ **Оптимізований моніторинг** - перевірка регіонів лише при зміні `lastActionIndex`
- ✅ **Підтримка кількох регіонів** - можливість відстежувати необмежену кількість регіонів
- ✅ **Збереження стану** - автоматичне збереження статусу між перезапусками
- ✅ **Автоматичне завантаження файлів** - перевірка і завантаження аудіофайлів на сервер
- ✅ **Динамічне створення задач** - створення та видалення задач "на льоту"

## 📋 Вимоги

- Python 3.12+
- Пакети: `aiohttp`, `python-dotenv`
- Доступ до мережі (Ukraine Alert API + SPON сервер)
- Аудіофайли в форматі MP3
